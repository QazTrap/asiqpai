# ASIQPAI Studio (beta)

Вход: кнопка «ASIQPAI Studio — записать демо» на странице Music.

## Реализовано

- Биты из существующего tracks.json, отдельная запись микрофона или загрузка аудио.
- До 180 секунд вокала / 25 МБ загружаемого файла. Биты длиннее 180 секунд обрезаются в миксе.
- Сдвиг вокала в секундах, уровни бита и голоса, волновая форма.
- Три пресета EQ/компрессии/реверберации/задержки; эти эффекты не выдаются за ИИ.
- Два проигрывателя до/после, WAV PCM16 stereo 44.1 kHz, системная отправка файла там, где поддерживается.
- Реальная нейросетевая очистка DeepFilterNet, когда подключён отдельный worker.
- Ссылка организатору для ручной отправки скачанного файла. Автоматического конкурса, голосования, выплаты ASIQ нет.

## Подключение ИИ

Сначала развернуть отдельный Railway service с root directory `ai-worker` и Dockerfile в этой папке. Модель скачивается при сборке, её отсутствие останавливает сборку. Это CPU-сервис; стоимость определяется ресурсами хостинга, не является бесплатным API.

1. Сгенерировать секрет `openssl rand -hex 32`. Не коммитить его.
2. Установить `STUDIO_AI_TOKEN` в сервисе worker.
3. На существующем Node backend установить тот же `STUDIO_AI_TOKEN` и `STUDIO_AI_URL` — адрес worker без завершающего слеша. Предпочтительно приватная сеть Railway; для публичного адреса HTTPS обязателен.
4. Перезапустить backend. `/api/studio/status` проверяет готовность модели. В UI появится доступная галочка ИИ-очистки.
5. Выполнить реальную проверку вокала через Telegram на Android и iPhone, до публикации включённой функции.

Без настроенного worker студия работает с локальными эффектами, галочка ИИ недоступна и подписана «сервер не подключён». При ошибке ИИ не подменяется локальной обработкой: пользователь получает ошибку и может сам отключить галочку.

Node route проверяет существующую Telegram HMAC-авторизацию до чтения тела, принимает только бинарный WAV, ограничивает размер, параллельные запросы, устанавливает таймаут. PostgreSQL автоматически создаёт `studio_ai_usage`: 3 успешные обработки на пользователя за календарный день БД, ошибки возвращают квоту. Worker закрыт общим секретом, обрабатывает один запрос за раз, принимает только mono PCM16 <=180 s. Записи не сохраняются в БД/на диск и не отправляются третьему API. Заголовки авторизации и аудио не логируются.

## Ограничения первой версии

- Проект в памяти вкладки. Закрытие удаляет несохранённый дубль; WAV нужно скачать.
- На мобильных устройствах задержку записи корректировать вручную, писать в наушниках. Сворачивание останавливает и сохраняет текущий дубль.
- DeepFilterNet предназначен для улучшения речи, не автотюн и не генератор музыки. На пении/адлибах возможны артефакты; очистка по умолчанию выключена.
- Нет MP3-кодера, автотюна, автоматической коррекции ритма, серверного хранения, покупки лицензии.
- Экспорт не даёт лицензию на коммерческое использование бита.

## Проверки

`node --test tests/studio.test.mjs` — формат WAV, уровни, защита server routes (без платных сервисов).
`python -m unittest discover -s tests -p 'test_*.py'` — валидация WAV worker (нужен numpy).
Browser smoke test: открыть studio через приложение, загрузить отдельный вокал, получить before/after WAV, проверить смещение и длительность, записать тест микрофона. Нейросетевой контейнер и реальные устройства требуют отдельного smoke test в среде развертывания.

DeepFilterNet: https://github.com/Rikorose/DeepFilterNet (MIT / Apache-2.0). Python API: `df.enhance.init_df`, `enhance(..., pad=True)`.

## Результаты проверки этой версии

- 7 Node-тестов: WAV, уровни, квота, блокировка параллельных запросов, реальный HTTP-маршрут с тестовым worker.
- 4 Python-теста: PCM roundtrip, отклонение stereo, повреждённого и слишком длинного WAV.
- Headless Chromium, 390×844: загрузка вокала, два пресета, сдвиг, сброс устаревшего экспорта, скачивание stereo WAV 44.1 kHz, запись синтетического микрофона. Ошибок JavaScript и горизонтального переполнения нет.
- Браузерный тест использует подставные Telegram/API/бит и не подтверждает работу настоящего Telegram WebView, реального микрофона или модели.
- Нейросетевой контейнер не был собран/запущен в текущей среде. До включения ИИ обязателен smoke test его сборки и обработки реального вокала.

Повторить браузерный тест: установить Playwright в среде разработки и Chromium, затем `node tests/browser-smoke.cjs`. Для своего Chromium задать `STUDIO_BROWSER_PATH`.
